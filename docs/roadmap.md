# Delivery Roadmap

## Phase 1: Platform Skeleton

- Repository scaffold
- API service and health endpoints
- Dashboard shell
- Shared domain models
- Basic workflow state machine

## Phase 2: GitHub Ingestion

- GitHub App auth
- Webhook signature verification
- Workflow failure ingestion
- Raw artifact storage

## Phase 3: Repair Intelligence

- Failure classifier
- Context pack builder
- Patch generation strategies
- Safety policy enforcement

## Phase 4: Validation

- Docker sandbox runner
- Targeted test reruns
- Static checks and patch guards

## Phase 5: PR Automation

- Branch creation
- Commit generation
- Draft pull requests
- Repair explanation and confidence score

## Phase 6: Production Hardening

- Postgres persistence
- Redis-backed jobs
- Metrics, tracing, alerting
- Human approval options
